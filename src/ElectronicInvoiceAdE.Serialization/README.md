# ElectronicInvoiceAdE.Serialization

[![NuGet](https://img.shields.io/nuget/v/ElectronicInvoiceAdE.Serialization.svg)](https://www.nuget.org/packages/ElectronicInvoiceAdE.Serialization/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://github.com/Ub4thaan/ElectronicInvoiceAdE/blob/main/LICENSE)

`ElectronicInvoiceAdE.Serialization` provides high-performance, fault-tolerant XML and JSON parsers and serializers for Italian Electronic Invoicing (**Fatturazione Elettronica**), conforming to **Agenzia delle Entrate Technical Specifications v1.9.1**.

---

## Key Features

- **Resilient XML Parsing**: Custom `XmlMapper` designed to handle real-world ministerial and ERP variations:
  - Tolerant to any XML namespace aliases (`p:`, `b:`, default namespaces, or mixed).
  - Handles missing optional nodes, irregular casing, and self-closing tags gracefully.
- **Legacy Codepage Support**: Seamless handling of invoices encoded in `windows-1252` and `ISO-8859-1` generated by older accounting systems.
- **Strict & Clean Serialization**: Writes fully compliant, indented or compact XML validated against ministerial schemas.
- **JSON Round-Trip**: Native serialization to/from JSON for modern REST APIs, message brokers, and document databases.

---

## Installation

```shell
dotnet add package ElectronicInvoiceAdE.Serialization
```

---

## Quick Example

```csharp
using ElectronicInvoiceAdE.Serialization;

// Read invoice from file, stream, or string
InvoiceReader reader = new InvoiceReader();
var invoice = reader.ReadFromFile("IT01234567890_00001.xml");

// Serialize invoice back to compliant XML
InvoiceWriter writer = new InvoiceWriter();
string xml = writer.WriteToString(invoice, indented: true);

// Serialize to JSON
string json = JsonSerialization.Serialize(invoice, indented: true);
```

## Part of ElectronicInvoiceAdE

This package is part of the modular [ElectronicInvoiceAdE](https://github.com/Ub4thaan/ElectronicInvoiceAdE) suite:
- `ElectronicInvoiceAdE`: Complete high-level facade.
- `ElectronicInvoiceAdE.Core`: Domain models and catalogs.
- `ElectronicInvoiceAdE.Serialization`: High-performance XML/JSON serialization (this package).
- `ElectronicInvoiceAdE.Validation`: Fiscal checksums (Partita IVA, Codice Fiscale) and official SdI rules.
- `ElectronicInvoiceAdE.Security`: Digital signature (.p7m / CAdES-BES) extraction and ZIP archive processing.
- `ElectronicInvoiceAdE.Data`: Entity Framework Core relational mappings and DbContext.
